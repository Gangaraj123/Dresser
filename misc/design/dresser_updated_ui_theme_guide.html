Development Guide
Flutter Implementation · Architecture · Packages · Code Patterns

Typography Setup

Use google_fonts package. Display font: Cormorant Garamond (serif) for all screen titles, stat numbers, brand name. Body font: Plus Jakarta Sans for everything else. Never use system fonts.

// In theme.dart
textTheme: TextTheme(
  displayLarge: GoogleFonts.cormorantGaramond(
    fontSize: 30, fontWeight: FontWeight.w600,
    color: Color(0xFF1A1A1A),
  ),
  bodyMedium: GoogleFonts.plusJakartaSans(
    fontSize: 14, fontWeight: FontWeight.w400,
    color: Color(0xFF666666),
  ),
)

Color Constants

Define all colors in a single class. Black is primary — accent colors only appear where they carry semantic meaning.

class DresserColors {
  static const primary = Color(0xFF1A1A1A);
  static const background = Color(0xFFFFFFFF);
  static const surface = Color(0xFFF5F5F5);
  static const border = Color(0xFFE8E8E8);
  static const textSecondary = Color(0xFF666666);
  static const textTertiary = Color(0xFF999999);

  // Semantic accents
  static const sage = Color(0xFF5C8A6E);
  static const blush = Color(0xFFD4726A);
  static const steel = Color(0xFF6B89A8);
  static const gold = Color(0xFFC4985A);
  static const lavender = Color(0xFF9B8BB4);
}

Pill-Shaped Buttons

All buttons use StadiumBorder() for pill shape. Three variants: dark filled (primary CTA), light outlined (secondary), ghost (inline actions with subtle shadow).

ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: DresserColors.primary,
    foregroundColor: Colors.white,
    shape: StadiumBorder(),
    padding: EdgeInsets.symmetric(
      vertical: 16, horizontal: 28),
    elevation: 0,
  ),
  child: Text('Save to wardrobe',
    style: GoogleFonts.plusJakartaSans(
      fontWeight: FontWeight.w600)),
  onPressed: () {},
)

Frosted Glass Bottom Nav

Custom bottom nav using ClipRRect + BackdropFilter. Active tab gets #F5F5F5 background pill. Don't use Flutter's built-in BottomNavigationBar.

Garment Card Component

2-column grid with GridView.count(crossAxisCount: 2). Each card: 3:4 image ratio, frosted heart overlay, pill category badge, color match score. Use CachedNetworkImage with shimmer.

Container(
  decoration: BoxDecoration(
    borderRadius: BorderRadius.circular(18),
    color: Colors.white,
    border: Border.all(
      color: Color(0xFFF0F0F0)),
  ),
  child: Column(children: [
    // Image with overlays
    AspectRatio(
      aspectRatio: 3/4,
      child: Stack(children: [
        CachedNetworkImage(...),
        // Frosted heart button
        Positioned(top: 10, right: 10,
          child: _buildFrostedCircle(
            child: Icon(Icons.favorite))),
        // Category pill
        Positioned(bottom: 10, left: 10,
          child: _buildFrostedPill('Shirt')),
        // Match score
        Positioned(bottom: 10, right: 10,
          child: _buildScoreBadge('5/5')),
      ]),
    ),
    // Info section
    Padding(padding: EdgeInsets.all(14),
      child: Column(...)),
  ]),
)

Frosted Glass Overlays

Used for hearts, category badges, match scores, bookmark buttons on images. White background at 90% opacity with 8px blur.

Widget _buildFrostedCircle({
  required Widget child}) {
  return ClipRRect(
    borderRadius: BorderRadius.circular(50),
    child: BackdropFilter(
      filter: ImageFilter.blur(
        sigmaX: 8, sigmaY: 8),
      child: Container(
        width: 32, height: 32,
        color: Colors.white.withOpacity(0.9),
        alignment: Alignment.center,
        child: child,
      ),
    ),
  );
}

Animation Strategy

Use flutter_animate for staggered reveals. Grid items fade + slide up with 50ms delay between each. Chat messages slide from left (AI) or right (user). Keep all durations 200-400ms with Curves.easeOutCubic.

// Staggered grid reveal
GridView.count(
  crossAxisCount: 2,
  children: garments.indexed.map(
    (i, garment) => GarmentCard(garment)
      .animate()
      .fadeIn(duration: 300.ms,
        delay: (i * 50).ms)
      .slideY(begin: 0.1, end: 0,
        curve: Curves.easeOutCubic),
  ).toList(),
)

Color Match Scoring UI

Score badges use semantic colors: 5/5 & 4/5 = sage green bg, 3/5 = gold bg, 2/5 & 1/5 = blush bg. All at 12% opacity for subtlety.

Widget _buildScoreBadge(int score) {
  final color = score >= 4
    ? DresserColors.sage
    : score == 3
      ? DresserColors.gold
      : DresserColors.blush;

  return Container(
    padding: EdgeInsets.symmetric(
      horizontal: 8, vertical: 4),
    decoration: BoxDecoration(
      color: color.withOpacity(0.12),
      borderRadius: BorderRadius.circular(50),
    ),
    child: Text('$score/5',
      style: TextStyle(
        color: color,
        fontSize: 9,
        fontWeight: FontWeight.w600)),
  );
}

Dark Theme Mapping

For dark mode, invert the B&W foundation. Accent colors stay identical — they're already designed to work on both.

// Dark theme overrides
static const darkBg = Color(0xFF121212);
static const darkSurface = Color(0xFF1E1E1E);
static const darkCard = Color(0xFF252525);
static const darkBorder = Color(0xFF333333);
static const darkText = Color(0xFFF0F0F0);
static const darkText2 = Color(0xFFA0A0A0);
static const darkText3 = Color(0xFF666666);

// Accent colors UNCHANGED:
// sage, blush, steel, gold, lavender
// all stay the same hex values

Design Rules Summary

Radius: Buttons = 50px (pill). Cards = 18-20px. Inputs = 14px. Tags = 50px (pill). Icons in circles = 50%.

Borders: 1px solid #F0F0F0 for cards. 1.5px solid #E8E8E8 for inputs. 1.5px dashed #DDD for upload areas.

Shadows: Cards only: 0 1px 4px rgba(0,0,0,0.03). Never on buttons, tags, or nav. Phone-level only: frosted glass blur.

Spacing: Screen padding: 20px horizontal. Section gaps: 20-24px. Card padding: 14-16px. Stat pills: 14px internal.

Icons: Lucide Icons, stroke 1.5px, 18-22px size. Black for active, #BBB-#999 for inactive.
