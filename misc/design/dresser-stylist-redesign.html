Why This Is Better Than Chat
No blank canvas problem
Chat UIs start with an empty screen and a blinking cursor — intimidating. The occasion grid gives users immediate tap targets. They don't have to think about what to type.
Structured inputs beat free text
Instead of "describe your event," users tap chips: Restaurant + Smart Casual. Faster, less ambiguous, and gives the AI better-quality input. Free text is still available as an optional field.
Results feel curated, not generated
A big outfit card with large garment photos, a "Why this works" explanation, and a styling tip feels like a stylist's recommendation — not an AI response. Swipe for alternatives like dating apps, not scrolling through chat history.
Weather context is proactive
The dark "Right now" card shows today's weather and a ready-made suggestion before the user even asks. The assistant is already thinking about their day — that's what makes it feel like a real stylist.
History builds trust
"Recent looks" at the bottom shows past styling sessions with scores. The user can see the AI has been consistently good. This builds trust in the recommendations over time.
Two clear actions
"Wear this" (logs to calendar immediately) and "Save outfit" (adds to collection). No ambiguity about what to do next. In chat, the user has to decide what to say next — here, they just tap.
Flow for Your Agent
The Stylist tab has 3 states:

State 1 — Home: Occasion grid (2×2 cards + horizontal scroll extras), search/prompt bar at top, weather context card (dark), recent styling history list. User either taps an occasion card OR types in the prompt bar.

State 2 — Refinement: After selecting an occasion, show structured chip selectors (Where? Vibe?) plus an optional free-text field for extra context. "Style me ✨" button triggers Gemini. Show a loading state with italic text.

State 3 — Results: Swipeable PageView of outfit cards (3 suggestions). Each card shows: outfit name, piece count, match score, large garment photos with labels, "Why this works" section (gold star badge), styling tip (lightbulb), and two action buttons (Wear this / Save outfit). Dot indicators show 1 of 3. Swiping horizontally moves between suggestions.

Use PageView widget with PageController for swipeable cards. NOT a chat ListView. The text input bar on the home state is a single-line prompt, not a multi-turn chat. Each styling request is independent — there's no conversation history or message bubbles.
