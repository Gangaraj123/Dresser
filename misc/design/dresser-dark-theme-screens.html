Dark Theme Mapping Rules
Backgrounds
#FDFAF6 → #1A1815 (primary)
#F5F0E8 → #242120 (secondary/cards)
#EDE7DB → #2E2B28 (tertiary/borders)
#FFFFFF → #242120 (elevated cards)
Text
#1A1815 → #F5F0E8 (primary)
#6B6560 → #A09A94 (secondary)
#9B9590 → #6B6560 (tertiary)
Accent
#C67D4A → #D4935E (primary)
#A85D2E → #E8A872 (dark/text)
#F5E6D8 → #2E2520 (light bg)
Semantic Tags (Dark)
Season: bg #1a2e1f, text #6fcf97
Formality: bg #1a2433, text #7bafdb
Fabric: bg #2a1a30, text #c78ddb
Pattern: bg #2e2210, text #e8a84c
Match badge: bg #1a2e1f, text #6fcf97
Borders
Light: rgba(26,24,21, 0.08)
Dark: rgba(245,240,232, 0.08)
Same opacity, inverted base color.
Dashed borders use #2E2B28 (bg3).
Key Principle
Warm dark, never cold. Background is dark brown, not black (#000). The app should feel like a dimly lit boutique, not a dark terminal. Color swatches stay the same in both modes.
